# 完整設計的覆蓋走查

日期：2026-10-15。對象：[完整設計稿](back-translation-spec.md)。這是規格與對話案例的人工走查，不是實作測試、真人能力測驗或學習成效驗證。

## 已完成的真人討論

- 使用者確認主動表達與舉一反三為主，一至三句、文字、約十分鐘試走。
- 接受原文閱讀安排、彈性提示與直接示範、完整修訂及少量重點、再運用。
- 要求其他情境與深度比較，檢視案例後選擇 B 為主、需要時 C。
- 接受單一 skill 與兩種入口；經澄清保存需求後，選擇本版只做單次練習。

2026-10-15，使用者針對整份交付稿的最後檢視回覆「沒什麼問題」，確認定稿。這是設計確認，未宣稱使用者已實際完成回譯或已透過此法改善能力。

## 走查時修正的容易混淆之處

- 「完整修訂」安排在自修提示之後，避免先給答案又要求猜。
- 「自己先翻中文」可能已接受句型教學，後續回譯不能稱為完全無提示表現。
- 回饋深度與重點數量分開；C 不等於增加所有相關考點。
- 單次練習仍有簡短收尾，但不要求使用者保存摘要，也不把收尾視為長期追蹤功能。
- 原文比較不等於每句都要換成原文；當原文有誤，應保留正確的學習者版本。

使用者確認整體設計，沒有提出修訂。整體流程、例外處理、回饋深度與單次範圍已完成本次設計所需的討論與檢視；沒有剩餘必要設計問題。設計版本 1.0 可供後續實作。
