# 單次回譯英文練習：完整設計稿

設計版本：1.0，2026-10-15。狀態：使用者完成整體檢視並確認定稿，可供後續實作。本次未建立、安裝或發布 skill／plugin。

後續狀態：本設計的首版實作已完成，見 [成品與驗證](../../README.md)。下文保留設計定稿時的範圍與走查描述；實際對話評估另記於實作交付資料。

## 1. 目的與完成條件

幫助繁體中文使用者，把閱讀時認得的英文轉成自己能主動表達的英文。回譯用來發現表達缺口，並透過解釋、自我修訂及新情境運用，建立可重用的判斷方法。

初版為**單次、一至三句、約十分鐘的文字練習**。依材料與使用者需求可縮短，不以固定時長限制完成。目標是理解與主動表達，不用原文相似率打分。

一次練習在以下情況收束：完成回譯與回饋，並做過一題新情境產出；或使用者明確選擇跳過、縮短或結束。沒有作答或沒有再運用時，如實說明，不代寫使用者答案。

## 2. 方法與研究定位

此處的教學回譯為：**英文原文 → 繁中意義提示 → 學習者重新用英文表達 → 修訂、比較及再運用**。它不是問卷驗證的回譯，也不是逐字還原測驗。[Zhang & Gao 的教學文章](https://files.eric.ed.gov/fulltext/EJ1029177.pdf)直接描述類似流程，容許教師提供母語譯文，並提醒同一意思可能有多種適切答案。

直接研究提供一些潛力線索，但不足以保證本案 AI、成人、繁中版本的成效。[韓國高中生研究](https://journal.kci.go.kr/meeso/archive/articlePdf?artiId=ART002617148)為 21 人單組前後測，欠缺對照組。糾錯、解釋及提取研究屬相鄰依據，不能當成本流程已證實優於其他練習。

一至三句、約十分鐘、每輪一至三個重點，以及 B／C 深度安排，是本次確認的產品與教學選擇，不是研究測出的最佳參數。完整來源與限制見 [方法研究](../research/back-translation-method.md) 與 [回饋研究](../research/feedback-and-transfer.md)。

## 3. 使用入口與觸發範圍

採**單一回譯 skill 核心**，支援兩種入口，日後可由 plugin 封裝。Skill／plugin 能力的官方依據見 [封裝研究](../research/skill-plugin-boundary.md)。

| 入口 | 例子 | 起點 |
| --- | --- | --- |
| 獨立練習 | 「用回譯法練習這段英文」 | 理解原文、選擇中文準備方式 |
| 其他流程交接 | 閱讀文章時，將其中兩句交給回譯練習 | 沿用已提供且經檢查的材料，只補缺少步驟 |

只收到英文不自動啟動；單純翻譯、改稿或句型問答仍依原任務處理。既有練習中說「直接翻譯」「直接告訴我」「講深入一點」是調整本輪支架，不自動取消整個練習。

不要求安裝其他翻譯或句型 skill 才能完成核心教學。共用指同一套流程與規則，不假設存在可程式呼叫的 skill API，也不自行向另一聊天傳訊。

## 4. 材料與單次狀態

當輪需區分：英文原文及必要語境、目前採用的中文提示、學習者原始回譯稿、後續修訂與提示、目前階段，以及使用者當輪的時間或深度偏好。

- 英文原文必須有；缺少時先請使用者提供，不自行捏造比較基準。
- 交接可附中文提示、真實回譯稿與已完成階段；需要檢查原文對應及可見依據，不盲目沿用。
- 若無法判斷原文意思而會影響教學，先釐清；不為了示範而自行添加人物、因果或情境。
- 長文先選一至三句語境足夠的片段並告知選段；優先尊重使用者指定部分。
- 沒有正式程度資訊時，先用短材料與實際答案調整支架，不強制先做程度測驗。
- 本輪偏好可調整；這不建立跨聊天的永久設定。

## 5. 教學流程

### 5.1 理解原文與準備中文

允許先讀原文。接著詢問：「這次想自己翻成繁體中文，還是由我提供？」明確要求 AI 翻譯時直接提供，已有答案時不重問。

**自行翻譯路徑**：檢查是否保留人物、動作、時序、否定、條件與必要語氣；修正影響意思的理解偏差，解釋差異，再以修訂後的中文繼續。一般以 B 深度解釋，不把中文潤稿當主要教學。

**AI 翻譯路徑**：提供自然、保留原意的繁中提示，不為了暗示答案刻意照搬英文語序；必要背景用短語補足。使用者可提出疑問或修訂。

提示無待釐清之處即可往下走，不額外要求一次形式上的「確認」。若中文已漏掉資訊，先修好再出題。

### 5.2 學習者回譯

只重貼核定中文提示，請使用者用英文表達。提醒可留空、用中文占位或求助。回譯期間不再重貼完整英文原文；聊天前文仍可能可見，不能宣稱已強制隱藏或是嚴格閉卷。

等待真實答案，不把示範稿或 AI 推測當作學習者作答。若在第一段已教過某用法，後續判讀應知道學習者已接觸過該答案，不能稱為完全無提示的表現。

### 5.3 評估與支援

同時檢查原文、中文提示與回譯稿。先確認材料沒有誤導，再判斷學習者答案。

| 教學功能 | 判準 | 做法 |
| --- | --- | --- |
| 待補英文 | 中文占位、留空、明確求助 | 提供合適詞句及短解釋，不當作已犯英文錯誤 |
| 優先修復關鍵意思 | 讀者可能無法理解，或理解到相反／顯著偏離的核心意思 | 指出具體誤讀與差別，必要時先問意圖 |
| 修復局部用法 | 文法、搭配或用詞有問題，但核心意圖仍可辨識 | 依價值挑重點解釋，其餘納入必要修訂 |
| 比較表達選擇 | 答案成立，或原文有值得學的結構 | 明確接受合理版本，再說情境、語域或表達效果 |

「問題類型」與「影響程度」分開：文法正確也可能意思反向；文法有錯也不一定嚴重。以上是教學功能，不是每輪必須印出的等級。沒有的階段略過，同一處只教一次。

對可能自行修復的一個重點，先給一次短提示，等待使用者回答。未知用法、中文求助、提示後仍卡住或要求直接答案時，直接示範。不要先貼完整修訂版，又要求使用者猜出其中答案。

### 5.4 完整修訂與分層解釋

提供保留原意、最低必要改動的完整修訂。原句已成立就可以保留；可選的風格變化與必要改正須分清楚。

預設深入解釋一至三個重點。說明學習者原句實際意思、修訂原因，以及能幫助下次選用的判準。其餘必要修正仍反映在完整稿中，可依要求展開。

| 深度 | 內容 | 使用方式 |
| --- | --- | --- |
| A 精簡修正 | 修正與最小對比 | 只需提醒、使用者想簡短時 |
| **B 理解對比** | 實際意思、目標差別、使用判準與短例子 | **預設** |
| C 結構與延伸 | 結構原因及與當前困難相關的延伸 | 使用者追問、B 後仍混淆或有值得深入的點時 |

深度與重點數量分開。展開 C 時可減少重點，不把每個相關句型全部列出。反覆出現相同困難時，可以提議對比或拆句練習；不能單憑一次錯誤就判定使用者缺乏某級能力。

### 5.5 原文比較

學習者已留下初稿後再比較英文版本。必要修訂、原文亮點與合理替代表達可自然合併講解，不重複一套糾錯。

比較要說明具體效果，不只說「母語者會這樣說」或「原文比較高級」。學習者版本更符合當前口語／工作情境時應保留；原文本身有問題則校正原文。

中文未提供的原文細節，可作補充觀察，不指控學習者漏譯；若要專練某個形式，另以加練要求明示。

### 5.6 新情境再運用與收尾

選一個本輪重點，換內容出一個短題，等待使用者產出，再提供短回饋。新題只練這個重點，不把未教過的複雜句型混入判定。

新題仍卡住時留在該點提供支架；可以簡化、直接示範或結束，不無限疊加題目。使用者可跳過，不將跳過視為失敗或已掌握。

用一至兩句總結本輪學習點及實際表現，例如：「這次區分了以前常做與已經習慣；你在提示後修正原句，並自行在新情境用出 be used to + V-ing。」未做新題則只描述已完成部分。此收尾不是長期紀錄或必須保存的摘要。

### 5.7 何時提議調整階段

正常略過空階段可直接做。若有具體理由，可以提出增加、合併、縮短或替換活動的選項，例如：

- 「這次主要卡在借入與借出的方向，要不要加一個換主詞的對比？」
- 「要不要只保留一個重點，其他延伸先略過？」
- 「這句已經成立；想加練的話，可以換成工作情境。」

不每輪強制詢問全套設定；使用者明確要求調整時依其偏好進行。

## 6. 代表性對話

以下是設計範例，不是使用者作答或學習成效。

### 6.1 自行英翻中時理解偏差

**原文**：I'm used to working late.

**學習者中文**：我以前常工作到很晚。

**教練**：這裡有一個重要差別：原文是「已經習慣」，你的中文是「以前常做」。**I used to work late** 才是以前常做；**I'm used to working late** 是現在對這件事不陌生。因此這輪中文改成「我已經習慣工作到很晚了」。接下來請依這個中文，用英文表達；回譯時先暫不看原句。

這一條路已先解釋句型；之後的成功只能描述為教學後的產出。

### 6.2 文法成立但角色方向反了

**原文**：I lent Amy NT$500.

**中文提示**：我借給 Amy 五百元。

**回譯稿**：I borrowed NT$500 from Amy.

**教練**：你的句子文法成立，但說的是「我向 Amy 借錢」，錢的方向反了。先想誰提供錢、誰借入：**I lent Amy NT$500** 與 **Amy borrowed NT$500 from me** 描述同一件事，只是視角不同。換個情境，用英文說：「Ben 向我借了一本書。」

若使用者已有可自行修復的線索，可先只指出方向並請他改；以上為需要直接解釋時的 B 版。

### 6.3 正確替代表達與原文亮點

**原文**：I couldn't agree more.

**中文提示**：我完全同意。

**回譯稿**：I totally agree.

**教練**：這句正確，可以保留。原文是在說「同意程度已到頂，不可能再更同意」，也是強烈贊同。類似的 **I couldn't be happier** 表示非常開心。若想練這個表達，可以試著說「我完全同意你的建議」。

其餘案例見 [對話原型](teaching-loop-prototype.md) 與 [回饋深度比較](feedback-depth-comparison.md)：包括中文占位、提示漏資訊、原文錯誤與不同深度。

## 7. 共用時的交接規則

其他流程可交接英文、語境、中文提示、學習者原稿與已完成階段。確認對應後從適當階段繼續；已做過的步驟不機械重跑。

當輪結束時，可在原對話用短收尾銜接回文章閱讀或其他任務。學習者未作答、用了提示或跳過新情境等情況須如實區分。這不是自動跨聊天傳輸或跨 skill 執行協定。
