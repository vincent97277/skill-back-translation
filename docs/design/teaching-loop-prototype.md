# 教學循環：對話原型（可丟棄草稿）

日期：2026-10-15。用途：檢查教學順序、回饋口吻與階段調整是否合適；不是已完成的規格，也不是學習成效證據。

後續狀態：使用者已檢視延伸案例並選定回饋深度；本稿保留最初原型，正式決策見 [完整教學循環](../../.scratch/back-translation/issues/04-teaching-loop.md)。

## 本次想回答的問題

相同中文提示下，學習者可能求助、偏離意思，或寫出與原文不同但正確的答案。教練能否用不同且適量的回饋，幫助學習者理解並再運用？何時值得提議調整階段，而不讓練習變成反覆設定流程？

以下學習者發言皆是自擬案例，並非使用者實際練習紀錄；不能拿來當作使用者已檢視或接受的證據。

## 已確認的設計約束

- 目標為主動表達及遷移運用；原文不是唯一答案。
- 初次試走為一至三句、文字互動、約十分鐘。
- 先理解原文，回譯時暫不看，提交後比較。聊天前文可能仍可見；不宣稱強制隱藏或嚴格閉卷。
- 可自己練習英翻中，也可由 AI 提供；用保留意思的繁中提示繼續。
- 對可能自行修正的重點先給一次短提示；中文占位、明確求助或未知用法直接示範。使用者可隨時要求直接答案。
- 保留使用者意圖，提供完整修訂版；深入講解一至三點，沒有問題的階段略過。提示互動尚未完成時，先不貼出會洩漏提示答案的完整修訂版。
- 選一個學習點，換個情境再產出；使用者可跳過或結束，不能把未作答記成已會。
- AI 可以提出是否需要調整、增加或減少教學階段。

## 候選流程

1. **接收與理解原文**：確認語境是否足夠；長文先挑一至三句。若歧義會影響提示，先釐清；單純有可行替代解讀則保留條件，不自行杜撰背景。
2. **準備中文提示**：詢問自翻或 AI 翻譯。自翻時先處理影響意思的理解偏差，不把中文修辭教學當主要任務。中文確認後才往下走。
3. **自行回譯**：只重貼中文提示，請學習者用英文表達；允許留空或中文占位，不預先給完整英文答案。
4. **依答案提供支援與修訂**：先檢查中文提示品質，再辨認待補英文與影響意思的地方；只對適合自行修復的一個重點先提示，等待答案後再揭示完整修訂。其他問題可直接示範。維持一至三個深入講解重點。
5. **比較表達選擇**：區分錯誤、合理替代表達、語域選擇及原文亮點。學習者版本已自然正確時，可直接肯定並短講一個值得觀察的差別。
6. **新情境再運用**：用一個短題請學習者主動產出，再依其新答案給短回饋；新情境未答對時，留在這一步提供支架，不再疊加新考點。
7. **收束與可選調整**：記下這次真正練過的學習點。只有有具體調整理由或使用者表達偏好時，才提出調整選項；平常不強制詢問。

步驟 4 與 5 可在同一則回饋自然合併；上面是教學功能，不要求在使用者面前印出七個標題。這是候選流程，尚待使用者檢視例子。

## 共用材料

語境：收到邀請後，因不知如何婉拒而拖延回覆。

**英文原文**：I put off replying because I wasn't sure how to say no politely.

**核定中文提示**：我遲遲沒有回覆，因為我不確定該怎麼有禮貌地拒絕。

此例的「拒絕」指拒絕邀請，並非拒絕回覆。若沒有邀請語境，教練不應自行假定具體拒絕的是什麼。

## 案例 A：中文占位，無須製造錯誤

**學習者**：I delayed replying because I wasn't sure how to 婉拒.

**教練**：

> 你已把「延後回覆」表達出來了。「婉拒」在這裡可以用 **say no politely**，就是有禮貌地說不。
>
> 補完整是：**I delayed replying because I wasn't sure how to say no politely.**
>
> 這句成立。原文的 **put off replying** 也表示把回覆往後延；這個語境中，兩種都能用，put off 是很實用的日常說法。
>
> 換個情境試試：用 **put off + V-ing** 表達「我一直拖著沒打那通電話」。

**學習者**：I kept putting off making that phone call.

**教練**：

> 對，**kept putting off** 也帶出反覆拖延的感覺。這次你在新情境用出了 put off + V-ing。

觀察：中文占位直接支援；其他部分成立，不額外安排「重大錯誤」與「語意錯誤」段落。只記錄這次新情境成功，不宣稱日後一定記得。

## 案例 B：意思偏移，先提示一個可修復的重點

**學習者**：I refused to reply because I wasn't sure how to say no politely.

**教練（先提示，暫不貼出修訂版）**：

> 後半句已表達清楚。前半句 **refused to reply** 會讓人讀成「拒絕回覆」，但中文要表達的是「拖著、延後回覆」。
>
> 如果用 **put off** 表示延後，後面的 reply 要變成什麼形式？試著改前半句就好；也可以說「直接告訴我」。

**學習者**：I put off replying.

**教練**：

> 對，這裡用 **put off + V-ing**。完整是：**I put off replying because I wasn't sure how to say no politely.**
>
> **refuse to do** 是拒絕做；**put off doing** 是把事情延後。這個差別會改變讀者對你行為的理解。
>
> 換個情境：用 put off 表達「我因為不知道怎麼開口，所以拖著沒道歉」。

**學習者**：I put off apologizing because I didn't know how to start.

**教練**：

> 這句能表達那個意思，而且你把 put off 換用在 apologizing 上了。

觀察：不先講完整答案再要求猜；同一處 refuse / put off 差別只解釋一次，不在兩個錯誤階段重複計算。

## 案例 C：正確替代表達，縮短回饋

**學習者**：I delayed my response because I wasn't sure how to decline the invitation politely.

**教練**：

> 這句正確，在邀請的語境中也清楚。**decline the invitation** 直接指出拒絕的是邀請；原文的 **say no** 更口語，也適用於其他請求。這裡沒有需要修正的地方。
>
> 想練日常用法的話，試著用 **say no politely** 表達「我正在學習怎麼有禮貌地拒絕」。

**學習者**：I'm learning how to say no politely.

**教練**：

> 可以，這句自然。這輪可以在這裡結束。

觀察：不把較正式寫法判成錯誤；完整修訂版可直接說「原句可保留」，不為呈現改稿而改寫。是否仍提供新情境題，受本次時間與使用者意願調整。

## 案例 D：中文提示不足，先修復題目

若原文為 **She had already left when I arrived.**，中文提示為「我到的時候，她已經走了」，學習者寫 **She was already gone when I arrived.**，應接受此版本保留了必要時序；不能因未重現 had left 而判錯。

若本次要特別練過去完成式，可以說：「意思正確。要不要再寫一版用 had + 過去分詞，練習原文的表達？」這是加練選項，不是把正確答案降級。

若中文提示本身誤譯，例如寫成「我到的時候，她正要離開」，應先承認並修正提示，再讓學習者選擇重試或看差別；不能把依該提示作答的結果算成學習者語意錯誤。

## 案例 E：原文本身需要修正

若原文有 **I look forward to hear from you.**，而學習者寫出 **I look forward to hearing from you.**，應保留學習者版本，指出原文在這個用法中需要 hearing。原文校正是教練處理的材料品質問題，不強迫使用者模仿。

## Q6 補充：階段調整的候選策略

區分「正常略過空階段」與「改變練習安排」：

| 情況 | 候選處理 | 可對使用者說的話 |
| --- | --- | --- |
| 沒有重大或語意問題 | 直接略過空階段，縮短回饋 | 「這句成立，我們直接看一個表達選擇。」 |
| 目前程度尚不明 | 從短材料與實際作答觀察，不強制程度測驗 | 「先用這一句試試，我會依你卡住的地方調整提示。」 |
| 同一結構連續卡住 | 提議增加一個對比或拆句練習，再回到原任務 | 「這次主要卡在 refuse 和 put off 的差別，要不要先用兩個短句分辨？」 |
| 使用者覺得講太多或時間不足 | 提議省略延伸比較，保留一個核心學習點；可結束或跳過新情境題 | 「要不要縮成一個重點，其他延伸留到下次？」 |
| 學習者已自然正確 | 提議更短回饋，或改為更有挑戰的新情境 | 「這輪可以收束；如果想加練，我可以換成工作上的情境。」 |
| 使用者想練中文理解 | 下輪改走自行英翻中，優先解釋理解差異 | 「下輪要不要自己先翻中文，看看原文理解有沒有漏掉？」 |

不是每輪都要詢問「要不要增減階段」。只有存在明確可選的安排時才提議，選項以一個具體調整為主，不打開龐大的設定選單。

以上提議出現時機與措辭仍待使用者確認。原型不自行建立長期偏好、學習紀錄或排程。
