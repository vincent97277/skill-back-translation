## Question

哪些步驟構成可重用的回譯練習核心？獨立練習與其他工作流程使用它時，各自提供什麼上下文、交接什麼結果、保留多少學習狀態？選擇單一 skill、數個 skill 或 plugin 封裝的最小合適方案為何？

## Answer

2026-10-15，Q8 與 Q9 已由使用者確認。

- 採單一回譯 skill 作為教學核心，支援獨立完整練習，以及由其他英文／工作流程交接材料進入的兩種方式。未來可由 plugin 封裝，不需要為每個入口複製一套教學規則。
- 其他流程若提供英文原文、必要語境、中文提示、真實使用者作答與已完成步驟，可以沿用有依據且經檢查的材料，只補缺少的步驟。缺少英文原文或意思不清時，先補齊所需資訊；不得自行製造原文或學習者作答。
- 交接屬對話流程的設計，不假設已有可程式呼叫的 skill API，也不自行傳訊到其他聊天。
- 本版以單次練習為單位。當輪可沿用已提供的上下文、接受調整或結束；收尾以簡短學習點與實際產出回饋為主。
- 本版不建立長期學習紀錄、自動錯題庫、跨聊天程度追蹤或複習排程；也不要求使用者保存摘要才能正常使用。短收尾不是跨聊天保存方案。
- 教學結果只能描述本次實際表現，如提示後改正、獨立造句或未完成；不能聲稱已長期掌握。

討論資產：[共用邊界討論稿](../../../docs/design/reuse-contract-draft.md)。完整交付稿由後續設計檢視票整合。
