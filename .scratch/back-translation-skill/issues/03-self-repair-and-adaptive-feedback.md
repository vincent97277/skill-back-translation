# 03: 提示自修與可調整的教學節奏

**What to build:** 當使用者能自行修正、仍然卡住、想深入理解或希望縮短練習時，能在同一套完整回譯循環中得到一次有效提示、適時示範、B／C／A 深度調整，以及合適的活動增減。

**Blocked by:** 01 — AI 提供中文的完整單次回譯練習。

**Status:** closed

## Acceptance criteria

- [x] 對有依據可嘗試自修的一個重點，先提供短提示並實際等待回答；提示未完成時不給完整修訂或其他會洩漏該答案的內容。
- [x] 使用者提示後仍卡住，或明確說「直接告訴我」時，立即轉為合適示範與解釋，不連續要求猜答案；這項求助不被當成取消整個練習。
- [x] 自修成功或改為直接示範後，繼續完成修訂、原文比較、新情境與收尾，不把一次提示互動當成整個練習已完成。
- [x] B「理解對比」仍是預設；使用者追問原因或 B 後仍混淆時，可展開 C 的結構原理與相關延伸；要求簡短或只需提醒時，可縮為 A。
- [x] 深度與重點數量分開處理，深講時可減少考點；不因展開 C 就羅列所有相關句型，也不因縮短而保留錯誤解釋。
- [x] 沒有問題的階段直接略過；有具體困難時可提出一個增加、合併或縮短活動的選項，並尊重使用者回答，不每輪重新詢問全部設定。
- [x] 使用者說時間不足、跳過或結束時，調整或收束；新情境仍卡住時就地簡化或提供支架，不無限增加題目。
- [x] 收尾區分自行完成、提示後完成、已看示範及未作答，不把單次成功當成長期掌握或推定能力等級。
- [x] 用新材料分輪驗證提示等待、提示後修正、求助後示範、B 後追問、簡短模式、活動調整與提前結束；保存實際輸出與行為判準，重跑受到改動影響的基礎循環，維持結構檢查通過。
