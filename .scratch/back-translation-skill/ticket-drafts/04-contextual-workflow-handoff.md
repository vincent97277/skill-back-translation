# 04: 在其他流程中插入回譯並接回原任務

**What to build:** 文章閱讀或其他英文流程可以交接原文、必要語境、中文提示、真實回譯稿及已有進度；同一個 skill 檢查後從適當位置續接，完成練習後在原對話回到周邊任務，交付可獨立試用的完整首版。

**Blocked by:** 02 — 自行英翻中與材料修復的完整練習；03 — 提示自修與可調整的教學節奏。第一張為間接依賴，不重列。

**Status:** draft

## Acceptance criteria

- [ ] 從其他流程交接時，辨認並檢查原文、語境、中文提示、真實使用者原稿、已完成階段及當輪偏好；缺必要材料時先補齊，不捏造已完成的進度。
- [ ] 至少涵蓋三種入口進度：只有原文、已有可用中文但未回譯、已有中文與真實回譯稿。分別銜接適當階段，不無條件重做翻譯選擇或要求重新提交答案。
- [ ] 若上下文明確包含已給提示及等待中的回答，能正確延續自修或依求助示範；不能重置提示狀態，亦不能把未答的題目視為已完成。
- [ ] 交接材料有遺漏、誤譯或語境歧義時，先使用材料修復規則再繼續；沿用的學習者答案仍依同一套公平性、替代表達與回饋深度規則處理。
- [ ] 完成或提前結束時，以原對話中的簡短收尾銜接回閱讀等原任務；不自行向另一聊天傳訊，不把流程交接宣稱為已建立跨 skill API。
- [ ] 全部入口在無其他英文 skill、長期學習檔案或外部帳號時仍可運作；不加入長期紀錄、錯題庫或排程，也不要求使用者保存摘要。
- [ ] 用新材料實際跨輪驗證以上不同交接進度及完成後返回；評估側保留預期行為，受測側使用原始任務與所需材料，不靠看過答案的完整示範稿宣稱通過。
- [ ] 在整合成品上確認實作規格的行為覆蓋完整：兩種翻譯路徑、材料修復、提示自修、A／B／C、合理替代表達、新情境、跳過與結束及各入口銜接；修正失敗後重跑相關情境，保留實際輸出、判準與限制。
- [ ] 交付結構驗證通過且可獨立載入的 skill、必要資源、行為評估紀錄及本機載入或安裝方式；驗收不以固定標題或原文相似率評分，不自行安裝或發布。
