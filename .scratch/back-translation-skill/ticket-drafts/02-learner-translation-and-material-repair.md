# 02: 自行英翻中與材料修復的完整練習

**What to build:** 使用者可以選擇先自行英翻中，得到必要的理解修正，再依修訂中文完成既有回譯循環；材料不完整、有歧義、譯文漏資訊或原文本身有問題時，先處理材料而不誤判學習者。

**Blocked by:** 01 — AI 提供中文的完整單次回譯練習。

**Status:** draft

## Acceptance criteria

- [ ] 未表明偏好時提供自行英翻中或 AI 翻譯的選擇，並等待選擇或中文作答；已提供選擇或可檢查譯文時不機械重問。
- [ ] 自翻中文時檢查必要人物、動作、時序、否定、條件與語氣，修正影響意思的誤解並提供 B 深度解釋，再用修訂後的中文繼續；不將中文修辭潤稿變成主要課程。
- [ ] 自翻路徑最後也能完成學習者回譯、適當回饋、新情境及收尾，沿用同一套教學核心；中文無待釐清問題時，不增加形式上的確認輪次。
- [ ] 缺少英文原文或缺少影響解讀的語境時，先補齊所需資訊；不製造原文、人物背景或因果。長文先選語境足夠的一至三句並告知選段，尊重使用者指定部分。
- [ ] 中文提示遺漏或弱化了原文資訊時，接受根據提示作出的合理答案，先修復提示；額外觀察原文差異時不稱為使用者漏譯。
- [ ] 原文有可確認的用法問題時，先處理材料品質，保留正確的學習者版本，不要求模仿錯誤；不確定或依賴語境的情況明示條件或釐清意思。
- [ ] 中文階段已教過的答案或結構，不能在收尾被描述為完全無提示的能力表現。
- [ ] 用新材料實際跨輪驗證自行翻譯、中文理解偏差、缺原文、語境歧義、提示漏資訊及原文錯誤，並完成修復後的回譯與收尾；記錄實際輸出與判準。
- [ ] 重跑受到改動影響的 AI 中文基礎路徑，確認兩種翻譯選擇共用一致的提示公平性與等待規則；維持結構檢查通過。
